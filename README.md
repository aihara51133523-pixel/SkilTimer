# スキルバフタイマー

Windows用のシンプルなスキル効果時間タイマーです。

1. `release\BuffTimer.exe`を起動します（.NET 9 Desktop Runtimeが必要。このPCには導入済み）。
2. ホットキー欄をクリックしてスキルと同じキーを押します。初期値はQです。単一キーに対応します。
3. 効果時間を1〜9999秒で入力し、「動作開始」を押します。
4. ゲームで指定キーを押すとカウントダウンします。再度押すと最初から数え直します。長押しでの繰り返し入力は無視します。
5. 残り時間は `30.00` のように1/100秒単位で表示します。0秒になると効果音が一度鳴り、白文字の黒い縁が赤くなります。次の発動まで `0.00` を表示します。

表示更新の目標間隔は10ミリ秒です。実際の描画頻度は画面のリフレッシュレートやPCの負荷に依存します。残り時間は経過時間から計算するため、更新遅延が累積してタイマーがずれることはありません。

「動作終了」で監視とカウントダウンを停止し、初期秒数へ戻ります。アプリの×ボタンでオーバーレイも終了します。

表示は初回起動時にメイン画面の右上です。数字をクリックしてアクティブにし、そのままドラッグして移動できます。背景は透明で、最前面に表示されます。設定と終了時の表示位置を `%LOCALAPPDATA%\BuffTimer\settings.json` に保存します。

キーをゲームに渡したまま監視するWindowsのキーボードフックを使います。ゲーム固有の入力方式やアンチチートによって反応しない場合があります。排他フルスクリーンでは表示できない場合があるため、ボーダーレスウィンドウ表示を使用してください。ゲーム実機での互換性は未検証です。

## Visual Studio 2022での開発

Visual Studio 2022 17.12以降と「.NET デスクトップ開発」ワークロード、.NET 9 SDKを用意してください。
.NET 9とVisual Studioの対応バージョンは[Microsoftの対応表](https://learn.microsoft.com/dotnet/core/porting/versioning-sdk-msbuild-vs)を参照してください。

1. `SkilTimer.sln` をVisual Studio 2022で開きます。
2. 構成を `Debug`、プラットフォームを `Any CPU` にします。
3. `F5` でビルドしてデバッグ実行します。

コマンドラインでの開発: `dotnet build SkilTimer.sln` / 配布用出力: `dotnet publish BuffTimer.csproj -c Release -o release` / 時間計算検証: `BuffTimer.exe --self-test`（終了コード0なら成功）。
